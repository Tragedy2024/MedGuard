# MedGuard 知识库覆盖与扩充建议

范围为桌面 git/MedGuard 当前本地版本。统计字段完整性，抽查智慧医生的无联网路由。数量表示资料覆盖，医学准确性需要独立复核。

| 项目 | 当前数量 |
| --- | ---: |
| 疾病卡 | 8,803 |
| 单一科室字段 | 8,802 |
| 症状字段 | 8,783 |
| 检查字段 | 8,794 |
| 同时具有以上三个字段 | 8,773 |
| 症状导诊项 | 6,594 |
| 显式口语映射（有目标） | 23 |
| 主知识源索引条目 | 91 |
| 可选 OpenCMKG 扩展文档 | 15,397（本机配置关闭） |

本次生成的疾病卡不含病因、用药、治疗和并发症字段。疾病卡及扩展检索文档均无 1 型与 2 型糖尿病独立条目。无联网复测时，帕金森病的症状问法能展示相关字段，糖尿病和帕金森病的挂科问法被归为症状导诊，未返回科室。前者说明底座具备展示条件，后一问题需要修路由。增加资料不能替代这项修复。

## 候选资料及用法

| 来源 | 补什么 | 使用边界 |
| --- | --- | --- |
| [MedlinePlus Health Topic XML](https://medlineplus.gov/xml.html) | 常见病概述、病因、危险因素和检验解释，可先选 1 型与 2 型糖尿病独立主题 | XML 主体为英文、西班牙文，中文整理需核对。优先使用 [NLM 标明可复用的摘要](https://medlineplus.gov/about/using/usingcontent/)，署名并保留原文链接。关联站点原文、第三方药品专论及图片要单独核权。 |
| [WHO ICD-11 中文版](https://icd.who.int/browse/2026-01/mms/zh) | 规范病名、疾病编码、亚型标识 | 遵守 [WHO 署名及禁止演绎许可](https://icd.who.int/docs/icd-api/license/)，把产品别名映射与官方术语表独立维护。 |
| [中华医学会糖尿病学分会指南目录](https://diab.cma.org.cn/cn/zhinangongshi.aspx) | 核对中文疾病分型和适用背景 | 目录可公开查阅。整篇入库、翻译及对外分发需要核对具体文件授权。先保留引用链接和版本。 |
| [CMB 中文医学评测](https://github.com/FreedomIntelligence/CMB) | 可补充评测题的候选集 | 面向考试及病例问答，仍需自建口语、挂号、子型比较和拒答题。引用病例或题目时按各数据来源核对可再用范围。 |

对国赛原型，先修明确疾病直查科室及答案字段限制，再为演示和高频疾病补可引用的证据。可以选择 10–20 个疾病作为第一批，并覆盖作品要展示的提问。每条记录保存来源链接、版本、原文位置、适用人群和复核状态。在自有题集上比较新增资料前后的有效证据覆盖、误答、拒答及延迟，按实际缺口决定下一批扩充。
