# 按需检索与元数据过滤：实施记录

## 本轮实现

- 保留 BGE + BM25 + RRF、向量缓存、BGE 不可用时 BM25 回退及现有本人记录审计链路。
- 新增 `knowledge/strategy.py`，按确定性任务规则选择 `personal_sql / structured_lookup / hybrid / clarify / insufficient`。这是借鉴 Adaptive-RAG 思想的工程适配，没有训练原论文分类器。
- 本人记录走统一审计执行；通用药品注意事项和检验参考范围走知识库；简单疾病/症状事实直接查表，不额外调用生成模型。解释与比较选择混合检索；比较缺一个对象则澄清，证据缺一个对象则不生成完整比较。
- `MetadataFilter` 支持 kinds、entities、fields、sources、quality_tiers、source_versions。同维度 OR、跨维度 AND；BM25/BGE 在候选截断之前过滤。核心语料保留规则不能补回被过滤文档；无命中不会放宽条件。
- 元数据字段还限制最终给模型的证据正文。沿用原有 91/15305 文档粒度，没有新建子文档索引；字段过滤依据内容标签，暂不代表字段级向量模型。
- 保留显式疾病子型，支持一/二、Ⅰ/Ⅱ与1/2型书写归一；未收录子型不回退到父疾病。未新增任何糖尿病子型医学知识。
- 接口响应新增可选 `retrieval_plan`，记录策略、理由和过滤条件；它只是追踪信息，不授予访问权限。多轮追问使用已解析实体限制召回。
- OpenCMKG 文档适配读取原有字段标签及生成版本；第二路 RAG 仍默认关闭。未配置 LLM Key 时仍跳过 AI 兜底检索。
- 更新 OpenAPI、前端派生类型与 README，新增契约导出脚本。

## 验证

- 隔离副本后端完整回归：346 passed，27.28 秒。新增 25 项路由/过滤回归（含参数化用例）。
- 真实本地 BGE-small 离线加载探针：按药品类型、规范实体与 caution 字段过滤，命中 `drug_atorvastatin`；运行状态 `BGE + BM25`。单次首次请求 11.951 秒（包含模型初始化、读取已有向量缓存），随后单次暖态请求 0.013 秒。不是统计性延迟基准，不代表 P50/P95 或完整 LLM 回答耗时。
- 首次开发回归的四个失败来自隔离复制漏掉 tests/data 和未初始化演示库；补齐隔离测试数据后全部通过，未修改既有测试断言以掩盖失败。
- FastAPI 测试在 Windows 沙箱内的 socketpair 被阻塞，完整回归在获准的沙箱外隔离副本执行，测试配置禁用真实 LLM 与外部数据库。

## 仍然存在的边界

1. 路由为可解释的中文规则，口语、复杂省略、多种任务混合问题仍需扩充盲测；不宣称训练版 Adaptive-RAG 的研究性能。
2. 现有引用 ID/数字/药名门禁不是完整语义蕴含校验。本轮没有实现语义验证模型。
3. 元数据来源质量和版本必须由资料维护者提供；未知版本不能当成已审核。来源字段是筛选依据，不是临床权威性认证。
4. 当前未加入模型精排、开放网页检索或完整图检索，也未默认开启 OpenCMKG RAG。
5. 现有 Recall 指标不等于医学正确率；本轮没有付费生成评测或临床验证，也没有宣称召回提升百分比。
